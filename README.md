## 📌 About This Project

This project simulates a real-world Security Information and Event Management (SIEM) environment. Each alert represents a common security event that a Security Operations Center (SOC) analyst would investigate.

For every alert, I document:

- The alert details and severity level
- Log analysis and findings
- Triage decision (True Positive / False Positive)
- Incident notes and recommended response actions

This project demonstrates my understanding of security monitoring, log analysis, threat detection, and incident response fundamentals — key skills for any cybersecurity or SOC analyst role.
